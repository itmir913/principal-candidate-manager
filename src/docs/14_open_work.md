# 남은 작업

**남은 것만 적는다.** 끝난 항목은 이 파일에서 지운다 — 무엇을 언제 했는지는 git 이력이 기록한다.
여기 적힌 것은 근거가 아니라 **가설**이다. "이게 남았다"고 말하거나 손대기 전에 반드시 코드로 대조하라
(이름·경로는 바뀌었을 수 있다). 마지막 정리: 2026-10-08.

## 지금 대기 중

### 0.2.23 공개 — draft 준비 완료, Publish 만 남음

- 태그 `0.2.23` 은 `aaff071` 을 가리킨다(GPG 서명 annotated). 그 태그 ref 에서 `publish.yml` 을 실행해
  draft 릴리스를 만들었고 zip 이 첨부돼 있다. 본문은 직전 릴리스(0.2.21) 골격의 교사용 안내다.
- 배포된 최신(Latest)은 여전히 **0.2.21**. 0.2.22 는 태그만 하고 공개하지 않았으므로 0.2.23 이
  0.2.22 의 변경을 함께 담는다(CHANGELOG 0.2.23·0.2.22 절).
- 스키마는 v2 그대로, 마이그레이션 없음. 점수·순위 계산은 바뀌지 않았다.
- 배포 절차와 본문 양식: 태그 ref 에서 `publish.yml` 수동 실행(태그 push 는 워크플로를 돌리지 않는다),
  본문은 CHANGELOG 를 그대로 붙이지 않고 직전 릴리스 본문의 골격을 따른다
  (`gh api repos/itmir913/principal-candidate-manager/releases/tags/<직전버전> --jq .body`).

### 운영자 안내

0.2.23 부터 자동 추천은 시스템이 정할 수 없는 지점(모집단위 동점, 대학 동순위 경합 등)에서 멈추고
수동 확인 목록에 사유를 보인다. 운영자에게 "사유 확인 → 추천 확정 또는 미선발 처리 → 자동 추천 다시"
절차를 알려야 한다(사용 설명서 section5·앱 안 매뉴얼에 반영됨). 공개 전에 **작년 실제 데이터(익명화)로
라운드를 끝까지 돌려** 멈춤 빈도와 실제 결정의 차이를 보는 리허설을 권한다 — 코드 감사로는 안 보이는
운영 문제다.

## 아직 확인하지 않은 것

- **다른 관리자 탭의 재조회 실패 표시**: 라운드 화면은 "조작은 성공했는데 목록 재조회가 실패하면
  '오류'로 보이는" 문제를 고쳤다(`RoundsTab.vue::reloadAfter`). 대학·학생·학급·전형요소 탭에 같은
  꼴이 있는지는 보지 않았다.
- **학생·학급 가져오기의 행동 테스트**: 버튼을 눌러 요청과 화면 갱신을 보는 테스트가 없다.

## 알고 있지만 보류한 것

- **관리자 `GET /api/score-preview`(`scoring.rs::score_preview`)** — 2026-05-30 `eb293a8` 이후 어느 화면도
  부르지 않는다. 관리자 인증 뒤라 노출은 없고, 오류가 전부 500 이다(관례는 404/422). 2026-10-07 소유자:
  일단 둔다. 미사용 정리 때 제거하거나, 화면에서 다시 쓰게 되면 오류 코드를 관례에 맞춘다.
- **`unrecommend_result` 역방향 순위 가드 없음** — 2026-07-19 보류(명세 §4.3). 마감 검사가 대부분을 막는다.
  같은 계열: 다른 모집단위 추천을 취소해 자리를 만들면 2단계 병합과 다른 결과로 갈 수 있다(명세 §5.4).
- **담임 지원 수정 폼** — 수정 폼이 열린 지원을 상세 창에서 삭제해도 폼이 수정 모드로 남는다. 다시 저장하면
  같은 모집단위는 재생성, 다른 모집단위는 404. 의도인지 확인하지 않았다.
- **라운드 목록 재조회 실패 뒤** 화면에서 다시 받을 수단이 없다(브라우저 새로고침뿐). 상세는 전이 뒤
  상태로 보이고 목록 자리에 오류가 뜬다.
- **포기 처리의 진행 중 잠금 없음**(ResultsTab·RoundsTab `handleAbandon`) — 2단계 확인창이 중복 실행을
  막아 우선순위 낮음.
- **보류 정지 사유의 연쇄 노출 미언급** — 보류 덩어리에서 멈춘 대학 사유는 같은 순위의 다른 모집단위
  선두를 알리지만, 그 선두를 추천하면 뒤에 드러나는 후보가 덩어리를 막을 수 있다는 점은 말하지 않는다
  (거짓 문장은 아니고 누락).
