1. 시작하기 전에

시스템 요구 환경

  • 운영체제: Windows 10 / 11 (x64)
  • 브라우저: Chrome, Edge, Firefox 최신 버전 권장
  • 네트워크: 학내 LAN (인터넷 연결 불필요)

설치 및 첫 실행

  1. 1 공식 홈페이지(https://luminousky.com/teacher-utility-kit/principal-candidate-manager/)에서 최신 버전의 .zip 파일을 다운로드합니다.
  2. 2 다운로드한 압축 파일을 바탕화면에 압축 해제합니다.
  3. 3 principal-candidate-manager.exe를 실행하면 윈도우 시스템 트레이(화면 우측 하단)에 아이콘이 나타납니다.
  4. 4 시스템 트레이 아이콘을 클릭한 후 열기를 선택하면 브라우저가 자동으로 열립니다.
  5. 5

    브라우저가 열리면 다음 순서로 초기 설정이 진행됩니다.

    ①

    라이선스 동의

    이용 약관을 확인하고 동의합니다.

    ②

    관리자 비밀번호 설정

    관리자 계정의 비밀번호를 설정합니다. 이 비밀번호는 성적 입력·라운드 관리 등 핵심 기능에 사용됩니다.

    관리자 비밀번호를 분실하면 복구가 불가능합니다. 반드시 안전한 곳에 기록해 두십시오. 분실 시 데이터베이스 파일(pcm/data.db)을 삭제하고 프로그램을 재시작하면 초기화할 수 있으나, 모든 입력 데이터가 삭제됩니다.

실행 환경별 접속 방법

담당자 컴퓨터에서 실행하는 경우

담당자 PC가 켜져 있는 동안, 다른 담임 교사는 담당자 컴퓨터의 IP 주소를 브라우저에 입력하여 접속할 수 있습니다. 학교 내부 네트워크(LAN)를 이용하므로 인터넷 연결은 필요하지 않습니다.

별도 데스크톱 컴퓨터에서 실행하는 경우

해당 컴퓨터가 켜져 있는 동안 언제든지 접근 가능합니다. 대교협 진학 컴퓨터 등 교사망에 연결된 전용 컴퓨터에 설치하면 담당자 PC 종료 여부에 관계없이 안정적으로 운영할 수 있습니다.

데이터 저장 위치

모든 데이터는 실행 파일과 같은 폴더의 pcm/data.db 파일에 저장됩니다. 프로그램을 종료하거나 PC를 재시작해도 데이터는 유지됩니다. 정기적으로 이 파일을 백업해 두는 것을 권장합니다.

포트 변경

기본 포트는 8080입니다. 다른 포트로 변경하려면 실행 파일과 같은 폴더의 pcm/config.json을 텍스트 편집기로 열어 수정합니다. 

{
  "port": 8080
}

수정 후 프로그램을 재시작해야 반영됩니다.
