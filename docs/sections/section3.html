3. 관리자 사전 설정

라운드를 열기 전 학교장추천 담당자가 반드시 완료해야 하는 설정입니다. 아래 항목을 순서대로 진행하십시오.

3-1. 학급·담임 계정 설정

관리자 화면의 학급 관리 탭에서 학년·반별 담임교사 계정을 일괄 생성합니다. 화면의 양식 다운로드 버튼으로 양식 파일을 받아 작성한 뒤 업로드하면 계정이 자동 생성됩니다. 파일에 입력한 비밀번호가 그대로 계정 비밀번호가 되므로, 해당 비밀번호를 담임교사에게 안내하십시오. 담임교사가 비밀번호를 분실할 경우 관리자는 학급 관리 탭에서 새로운 비밀번호를 설정할 수 있습니다.

학년 반 담임명 비밀번호
1 1 담임A teacher1!
1 2 담임B teacher2@
2 1 담임C teacher3#
3 1 담임D teacher4$

3-2. 학생 기초데이터 업로드

학생 명부를 Excel 파일(.xlsx) 형식으로 준비한 후 관리자 화면의 학생 관리 탭에서 업로드합니다. 업로드 시 기존 데이터는 같은 학생 유형(재학생/졸업생) 기준으로 전체 교체됩니다. 헤더 행이 포함된 파일이어야 하며, 아래 열 이름을 반드시 포함해야 합니다.

학번 이름 학년 반 번호
10101 학생A 1 1 1
10215 학생B 1 2 15
20308 학생C 2 3 8
30122 학생D 3 1 22

3-3. 대학·모집단위 설정

관리자 화면의 대학 설정 탭에서 추천 대상 대학명, 모집단위명, 모집 정원을 입력합니다. 각 모집단위는 독립적으로 관리되며, 추후 전형요소 설정의 COMPOSITE 기준과 연동됩니다.

대학명 모집단위 정원
서울대학교 컴퓨터공학부 2
연세대학교 경영학과 3
고려대학교 의과대학 1
성균관대학교 소프트웨어학과 2
📷 스크린샷: 대학·모집단위 설정 화면

3-4. 전형요소 설정

관리자 화면의 전형요소 설정 탭에서 점수 산출에 사용할 전형요소를 정의합니다. 유형과 적용 범위의 조합에 따라 아래와 같이 구분됩니다.

NUMERIC — 수치형 입력

담임교사가 숫자를 직접 입력합니다. 최솟값(min)과 최댓값(max) 범위를 설정하고, 입력값을 점수로 환산하는 방식(높을수록 고득점 / 낮을수록 고득점)을 지정합니다. 예: 내신 등급 1~9, 낮을수록 고득점.

CATEGORY — 선택형 입력

담임교사가 미리 정의된 선택지 중 하나를 고릅니다. 각 선택지에 고정 점수를 매핑합니다. 예: 수상실적 — 금상 10점 / 은상 7점 / 동상 5점 / 없음 0점.

MANUAL — 관리자 직접 입력

관리자가 점수를 직접 입력합니다. 면접·서류 등 외부 기관 평가 결과처럼 학교 내부에서 산출할 수 없는 점수에 활용합니다.

SIMPLE — 공통 기준

모든 지원자에게 동일한 기준이 적용됩니다. 대부분의 전형요소에 사용합니다.

COMPOSITE — 조합별 기준

지원한 대학·모집단위 조합별로 다른 기준을 적용할 수 있습니다. 모집단위마다 면접 기준이 다른 경우에 활용합니다.

예시 시나리오

전형요소명 유형 범위 설명
내신 등급 NUMERIC SIMPLE 1~9등급, 낮을수록 고득점 환산
수상실적 CATEGORY SIMPLE 금상 10점 / 은상 7점 / 동상 5점 / 없음 0점
면접 점수 MANUAL COMPOSITE 모집단위별 면접 기준 상이
