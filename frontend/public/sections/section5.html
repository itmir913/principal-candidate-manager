5. 라운드별 역할 안내

이 장은 라운드 상태 3단계 — 진행중(OPEN) → 종료(CLOSED) → 마감(FINALIZED) — 순서를 따라, 각 단계에서 관리자와 담임교사가 화면에서 실제로 무엇을 눌러야 하는지 안내합니다. 상태 이름의 의미와 전체 흐름은 2장 「라운드 개념 이해」에서 먼저 확인하십시오.

담임교사는 지금 화면에 표시된 라운드 상태(진행중/종료/마감)를 확인한 뒤, 아래 5-1·5-2·5-3 중 해당하는 절의 👨‍🏫 담임교사 역할 상자만 읽으면 됩니다. 관리자가 하는 일까지 모두 읽을 필요는 없습니다.

5-1. OPEN 상태

OPEN

🛡️관리자 역할

  • 라운드 관리 탭의 라운드 열기 버튼으로 라운드 생성 및 진행중(OPEN) 상태로 전환
  • 담임교사에게 서버 IP 주소·입력 기간·마감일 공지
  • 개요 탭에서 담임교사별 입력 현황(등록 수·입력 확정 여부) 통계 확인
  • 전체 지원 현황 모니터링

👨‍🏫담임교사 역할

  • 담당 학급의 지원 희망 학생 등록
  • 학생별로 지원한 모든 대학·모집단위의 전형요소 값 입력
  • 점수 미리보기로 예상 점수 확인 후 저장
  • 입력 오류 시 해당 지원내역 수정·삭제
  • 모든 입력이 완료되면 화면 오른쪽 상단의 "입력 완료 확정" 버튼을 클릭하여 완료를 알린다. 확정 후 지원을 추가·삭제하면 확정이 자동으로 취소됨

🌐담임교사 접속 주소 확인 방법

관리자로 로그인한 후 개요 탭의 서버 접속 정보 항목에서 서버 IP 주소를 확인할 수 있습니다.

관리자 로그인 → 개요 탭 → 서버 접속 정보 → IP 주소 복사 후 담임교사에게 공유

📋지원서 입력 방법

학생에게 지원서를 받은 뒤, 해당 학생이 지원한 모든 대학·모집단위를 빠짐없이 입력합니다. 학생 한 명이 여러 대학·모집단위에 동시 지원할 수 있으며, 지원 건마다 전형요소 값을 별도로 입력해야 합니다.

✏️입력 내용을 수정해야 하는 경우

저장된 지원 내역을 클릭하면 상세 화면이 열리고, 여기서 수정 또는 지원 취소를 할 수 있습니다. 수정 화면에서는 학과명·전형요소 값은 물론 대학·모집단위 변경도 가능합니다. 라운드가 종료(CLOSED)되면 수정·삭제 모두 불가합니다.

🎓졸업생 지원자가 있는 경우

졸업생 지원자 입력은 담임교사가 없으므로 관리자가 직접 담당합니다. 로그인 화면의 학년 목록에서 졸업생을 선택하고 관리자 비밀번호로 로그인하면, 담임교사와 동일한 입력 화면에서 졸업생 지원자를 등록하고 전형요소 값을 입력할 수 있습니다.

로그인 화면 → 학년: 졸업생 선택 → 관리자 비밀번호 입력 → 졸업생 지원자 입력

5-2. CLOSED 상태

CLOSED

🛡️관리자 역할

  • 종료하기 버튼으로 라운드를 종료(CLOSED) 상태로 전환 (담임교사 입력·수정 즉시 차단)
  • 전환 시 모든 지원 내역의 점수 산출 및 순위 자동 계산
  • 산출된 점수·순위를 모집단위별로 검토
  • 결과 탭의 자동 추천 확정 버튼으로 전체 대학 일괄 처리, 대학별 이 대학 자동 추천 버튼으로 한 대학만 처리, 또는 학생별 추천 확정 버튼으로 직접 처리
  • 동점자 여부를 직접 확인하고 정원 초과 모집단위는 추천 대상을 직접 선택

⚡자동 추천 확정

결과 탭의 자동 추천 확정 버튼을 누르면 두 단계로 추천을 일괄 확정합니다. 대학 그룹 머리글의 이 대학 자동 추천 버튼을 쓰면 그 대학만 같은 방식으로 처리할 수 있습니다.

  • 1단계 — 모집단위별로 모집단위 순위순으로 잔여 정원까지 채웁니다.
  • 2단계 — 대학 전체 정원이 있으면 모집단위별 순서를 유지한 채 대학 전체 순위로 인원을 줄입니다. 대학 정원이 모집단위 합계보다 적으면 이 단계에서 줄어드는 것이 정상입니다.
  • 2단계에서는 각 모집단위의 다음 차례 지원자끼리만 대학 전체 순위로 겨룹니다. 따라서 같은 모집단위 안에서 순위가 낮은 지원자가 높은 지원자를 앞질러 추천되는 일은 없습니다. 대학 전체 순위가 높더라도 같은 모집단위의 상위 지원자에게 자리가 먼저 가면 이번 라운드에는 추천되지 않으며, 이는 그 모집단위 설정이 정상 적용된 결과입니다.
  • 정원이 무제한인 모집단위·대학은 컷이 걸리지 않습니다.
  • 동점이 정원 경계를 가르는 경우(잔여석보다 동점 인원이 많을 때)에만 그 동점 그룹을 자동 확정하지 않고 수동 확인 필요 목록(순위·잔여석·경합 인원 포함)으로 안내합니다. 그보다 상위인 학생은 그대로 자동 확정됩니다.
  • 정원이 동점 그룹 사이에 정확히 떨어지면 경계가 명확하므로 수동 확인이 필요 없습니다.
  • 버튼을 두 번 눌러도 이미 확정된 추천은 변경되지 않습니다.
⚠ 자동 추천 확정 후에도 수동 확인 필요 목록에 남은 항목이 있으면 직접 처리하십시오. 시스템은 동점자 중 일부만 고르지 않습니다 — 누구를 추천할지는 관리자가 판단해 학생별 추천 확정 버튼으로 처리합니다(정원 초과는 거부됩니다). 마감 전 모든 모집단위의 처리 여부를 반드시 확인하십시오.

⚖️동점자가 발생한 경우

시스템은 동점자를 자동으로 감지하거나 알리지 않습니다. 동점자는 같은 순위로 표시될 뿐이며, 관리자가 순위 목록을 직접 검토하여 판단해야 합니다. 동점자 중 모집 정원을 초과하는 경우, 추천할 학생을 관리자가 직접 선택한 후 추천 확정을 진행합니다.

🔢모집단위 순위를 건너뛴 추천은 거부됩니다

학생별 추천 확정 버튼을 누를 때, 같은 모집단위에 아직 추천되지 않은 상위 순위 지원자가 있으면 추천이 거부됩니다. 자동 추천이 모집단위 내부 순서를 지키는 것과 같은 규칙을 수동 추천에도 적용한 것입니다.

  • 동점자끼리는 서로 막지 않습니다. 우열이 정해지지 않은 상태이므로 관리자가 누구를 추천할지 선택할 수 있습니다.
  • 상위 지원자가 이미 추천 확정되었거나 미선발 처리된 경우에는 막지 않습니다.
  • 따라서 상위 지원자를 건너뛰어야 할 사정이 있다면, 먼저 상위 순위 학생을 미선발 처리해야 합니다(아래 항목 참고). 건너뛴 사실이 감사 기록으로 남습니다.

🚫미선발 처리 — 포기와는 다릅니다

라운드가 종료(CLOSED)된 동안, 선발하지 않기로 한 지원자를 미선발 처리합니다. 결격·서류 미비든 정원에 들지 못한 경우든 모두 이 기능을 사용합니다. 결과 탭의 학생별 행에서 미선발 처리 버튼을 누르고 사유를 입력하면 됩니다. 미선발 해제로 언제든 되돌릴 수 있습니다. 라운드를 마감하려면 모든 지원자에 대해 추천 확정 또는 미선발 처리가 완료되어야 합니다.

  • 미선발 처리된 지원자는 자동 추천 후보와 수동 추천의 순서 가드(위 항목) 양쪽에서 모두 빠집니다 — 즉, 다음 순위 지원자를 바로 추천할 수 있습니다.
  • 미선발 사유 입력은 필수이며, 미선발 처리·해제 모두 감사 기록에 남습니다. 결격인지 정원 미달인지는 사유 텍스트로 구분해 기록합니다.
  • 지원 포기(다음 페이지 참고)와 혼동하지 마십시오. 지원 포기는 라운드가 마감(FINALIZED)된 뒤 이미 추천된 학생이 진학을 철회하여 다음 라운드에 자리가 반환되는 것으로, 되돌릴 수 없습니다. 반면, 미선발 처리는 정원 집계에 영향을 주지 않고 언제든 해제할 수 있습니다.
  • 라운드를 다시 열면(재개방) 그 라운드에서 확정된 추천이 전부 초기화됩니다. 결격자 한 명 때문에 재개방하지 말고, 반드시 미선발 처리 기능을 사용하십시오.

🔓종료(CLOSED) → 진행중(OPEN) 역전환

종료(CLOSED) 상태는 다시 진행중(OPEN)으로 되돌릴 수 있습니다. 라운드 종료 후 담임교사가 입력 누락을 알린 경우, 라운드를 진행중(OPEN)으로 재전환하여 추가 입력을 허용한 뒤 다시 종료하면 됩니다. 단, 마감(FINALIZED) 상태는 어떤 상태로도 되돌릴 수 없습니다.

라운드가 종료(CLOSED)된 동안에는 순위의 기준이 되는 설정을 바꿀 수 없습니다 — 재학생 우선 설정(대학·모집단위)과 학생의 재학/졸업 구분이 그렇습니다. 저장된 순위는 종료 시점 기준으로 계산된 값이라, 기준만 바꾸면 순위와 어긋나기 때문입니다. 바꿔야 한다면 라운드를 다시 열고 → 설정·명단을 고친 뒤 → 다시 종료하십시오. 종료할 때 순위가 재계산됩니다. (정원 변경은 종료 중에도 가능합니다.)

⚠️주의 사항

  • "종료하기" 버튼을 클릭하면 학급별 입력 확정 현황이 먼저 표시됩니다. 미확정 학급이 있어도 종료 자체는 가능하지만, 해당 학급의 입력이 완전히 끝났는지 담임교사와 반드시 확인하십시오.
  • 점수 산출 중 오류가 발생하면 종료(CLOSED) 상태로 전환할 수 없습니다. 라운드 종료 전에 모든 담임교사의 입력 완료 여부를 반드시 확인하십시오.
  • 시스템은 추천 확정 누락을 자동으로 차단하지 않습니다. 마감하기 버튼을 누르기 전에 관리자가 모든 모집단위의 추천 확정 버튼을 빠짐없이 눌렀는지 직접 확인하십시오.
  • 마감하기 클릭 시 정원을 초과한 모집단위가 있으면 마감이 거부됩니다. 화면에 위반 모집단위 목록(모집단위 정원·추천 확정 수)이 표시되므로, 해당 모집단위의 추천을 정원 이내로 조정한 뒤 다시 마감하십시오.

5-3. FINALIZED 상태

FINALIZED

🛡️관리자 역할

  • 마감하기 버튼으로 라운드를 마감(FINALIZED) 상태로 전환
  • 라운드 관리 탭에서 전체 지원자 목록·라운드 결과 엑셀 다운로드
  • 엑셀 파일을 장부에 기록 후 잔여석 계산 및 공지
  • 포기 발생 시 잔여석 갱신 확인 후 재선발 여부 판단
  • 재선발이 필요한 경우 새 라운드 생성

👨‍🏫담임교사 역할

  • 마감 시점부터 소속 학생의 추천 확정 결과 조회 가능
  • 추천 확정된 학생이 지원을 포기할 경우 지원 포기 버튼으로 처리

📥결과 다운로드 안내

라운드 관리 탭의 다운로드 버튼을 통해 엑셀 파일 두 종류를 받을 수 있습니다. 이번 라운드 지원자 전체 명단, 추천 확정 학생 수, 모집단위별 잔여석이 자동으로 계산되어 제공됩니다. 해당 파일을 별도 장부에 기록해 두고 학교장추천인원 잔여석을 최종 집계한 뒤 공지하십시오.

🔄포기 발생 시 재선발 절차

포기가 발생하면 해당 모집단위의 잔여석이 갱신됩니다. 단, 시스템이 자동으로 후순위 지원자를 선발하지는 않습니다. 잔여석을 채우려면 새 라운드를 열어야 합니다.

포기 접수 → 잔여석 갱신 확인 → 새 라운드 생성 → OPEN → 재선발 진행

⚠️주의 사항

  • 지원 포기는 되돌릴 수 없습니다. 담임교사가 실수로 포기 버튼을 누른 경우, 새 라운드를 열어 해당 학생을 다시 입력한 뒤 즉시 라운드를 종료하고 추천 확정하는 방식으로 복구해야 합니다.
  • 추천 확정 누락을 마감 후에 발견한 경우, 새 라운드를 생성하여 누락된 지원자를 수동으로 입력한 뒤 다시 추천 확정을 진행해야 합니다.
  • 시스템은 한번 포기한 학생이 동일 모집단위에 재지원하는 것을 막지 않습니다. 학교장추천기준상 재지원을 제한해야 한다면 별도 장부로 내부 관리하십시오.

📋감사 기록 탭
