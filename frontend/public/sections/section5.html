5. 라운드별 역할 안내

5-1. OPEN 상태

OPEN

관리자 역할

  • 라운드 생성 및 OPEN 상태로 전환
  • 담임교사에게 입력 기간 및 마감일 공지
  • 전체 지원 현황 모니터링

담임교사 역할

  • 지원 희망 학생 등록
  • 대학·모집단위별 전형요소 값 입력
  • 점수 미리보기로 예상 점수 확인 후 저장

팁

점수 미리보기는 저장 전에도 확인할 수 있습니다. 단, 미리보기 결과는 저장이 완료되어야 공식 점수로 반영됩니다. 입력 완료 후 반드시 저장 버튼을 눌러 확정하십시오.

📷 스크린샷: 담임교사 전형요소 입력 화면

5-2. CLOSED 상태

CLOSED

관리자 역할

  • 라운드를 CLOSED 상태로 전환하여 입력 마감
  • 전체 학생 점수·순위 확인
  • 모집단위별 추천 대상 확정
  • 동점자 발생 시 수동으로 추천 대상 선택

담임교사 역할

  • 소속 학생의 점수·순위 조회
  • 입력·수정 불가 (읽기 전용)

동점자가 모집 정원을 초과하는 경우

  1. 시스템이 동점자 발생 상황을 감지하고 관리자에게 알림을 표시합니다.
  2. 관리자는 동점자 목록을 확인한 후 추천할 학생을 직접 선택합니다.
  3. 선택 완료 후 해당 모집단위에 대한 추천 확정이 가능해집니다.

주의

CLOSED 상태로 전환하면 담임교사의 전형요소 값 입력 및 수정이 즉시 차단됩니다. 전환 전에 모든 담임교사의 입력 완료 여부를 반드시 확인하십시오.

📷 스크린샷: 관리자 전체 점수·순위 확인 화면

5-3. FINALIZED 상태

FINALIZED

관리자 역할

  • 라운드를 FINALIZED 상태로 전환
  • 지원 포기 학생 처리
  • 포기자 발생 시 다음 라운드 생성하여 재선발 진행
  • 결과 파일 내보내기 및 데이터 백업

담임교사 역할

  • 소속 학생의 최종 추천 결과 확인
  • 지원 포기 의사 접수 및 보고

포기 발생 시 재선발 절차

포기 접수 관리자 포기 처리 새 라운드 생성 OPEN 재선발 진행

주의

FINALIZED 상태에서는 추천 취소가 불가합니다. 포기 처리만 가능합니다. FINALIZED 전환 전에 추천 대상을 신중히 확인하십시오.

📷 스크린샷: FINALIZED 상태 최종 결과 화면
