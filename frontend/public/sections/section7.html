7. 자주 묻는 질문

Q 여러 PC에서 동시에 접속할 수 있나요?

네. 프로그램은 관리자 PC 한 대에서만 실행하고, 담임교사들은 각자의 PC 브라우저에서 관리자 PC의 IP와 포트(예: http://192.168.0.10:8080)로 접속합니다. 동시 접속 인원 제한은 없으나, 반드시 같은 교내 네트워크(LAN) 안에 있어야 합니다.

Q 포트를 변경하려면 어떻게 하나요?

실행 파일과 같은 폴더의 pcm/config.json 파일을 텍스트 편집기로 열어 "port" 값을 원하는 번호로 수정합니다. 수정 후 프로그램을 재시작해야 변경이 반영됩니다. 기본값은 8080입니다.

Q 담임교사가 비밀번호를 분실했다면?

관리자 화면의 학급 관리 탭에서 해당 담임교사 계정을 선택한 후 비밀번호를 초기화할 수 있습니다. 초기화된 비밀번호는 담임교사에게 전달하고, 최초 로그인 후 즉시 변경하도록 안내하십시오.

Q 관리자 비밀번호를 분실했다면?

관리자 비밀번호는 다른 계정으로 초기화할 수 없습니다. 프로그램을 종료한 뒤 DB Browser for SQLite(무료) 같은 도구로 pcm/data.db를 열고, app_configs 테이블에서 admin_password_hash 행을 삭제한 뒤 저장합니다. 이후 프로그램을 재시작하면 관리자 로그인 화면에서 입력하는 비밀번호가 새 관리자 비밀번호로 설정됩니다.

Q 엑셀 파일 업로드 오류가 납니다. 어떻게 해야 하나요?

업로드 양식은 반드시 화면에서 제공하는 샘플 파일을 기준으로 작성해야 합니다. 열 이름(헤더)을 변경하면 오류가 발생합니다. 또한 숫자 열(점수 등)에 문자가 섞이거나 필수 값이 비어 있는 경우, 중복 행이 있는 경우에도 전체 업로드가 거부됩니다. 오류 메시지에 표시된 행 번호와 항목을 확인하여 원인을 수정한 뒤 다시 업로드하십시오. 이 프로그램은 엑셀(Excel)에서 테스트되었으므로, 타사 프로그램의 경우 CSV 파일로 저장하여 가져오기를 시도하십시오. 업로드 파일 크기는 최대 20MB이며, 초과하면 "업로드 파일 크기가 너무 큽니다" 오류가 표시됩니다. 이 경우 파일에 불필요한 서식·수식·빈 시트가 남아 있지 않은지 확인하고 정리한 뒤 다시 시도하십시오.

Q 담임이 지원 정보를 제출한 후 수정할 수 있나요?

라운드가 진행중( OPEN ) 상태인 동안에는 기존 지원을 취소하고 다시 등록하거나, 점수 데이터를 재제출할 수 있습니다. 라운드가 종료( CLOSED ) 또는 마감( FINALIZED ) 상태가 되면 담임 교사의 지원 정보 수정·취소가 불가합니다. 수정이 필요한 경우 관리자에게 라운드를 진행중(OPEN)으로 되돌려 달라고 요청하십시오.

Q 이미 종료(CLOSED) 상태인데 점수 기준을 수정해야 한다면?

종료( CLOSED ) 및 마감( FINALIZED ) 상태에서는 전형요소 설정(이름·점수 기준표)을 수정할 수 없습니다. 종료(CLOSED) 라운드라면 라운드 관리 탭에서 다시 열기 버튼으로 진행중(OPEN) 상태로 되돌린 뒤 수정할 수 있습니다. 다만 이미 마감(FINALIZED)된 다른 라운드가 하나라도 있으면 전형요소 설정 변경이 계속 차단되므로, 이 경우에는 수정할 수 없습니다. 따라서 점수 기준은 첫 라운드를 열기 전에 충분히 검토하여 확정하시기 바랍니다.

Q 동점자가 모집 정원을 초과하면 어떻게 처리하나요?

자동 추천 확정 버튼은 동점자가 잔여 정원 경계를 가르는 경우에만 해당 동점 그룹을 자동 확정하지 않고 수동 확인 필요 목록으로 남겨 둡니다. 그 목록에서 학생을 클릭하면 전형요소별 세부 점수를 확인할 수 있습니다. 이를 바탕으로 학교 내부 동점자 처리 기준을 적용하여 추천 대상자를 결정한 뒤 학생별 추천 확정 버튼을 누르십시오. 자세한 절차는 5-2. 종료(CLOSED) 상태의 「자동 추천 확정」 항목을 참고하십시오.

Q 데이터 정기 백업은 어떻게 하나요?

평소에는 관리자 화면 업데이트 & 백업 탭의 백업 파일 다운로드 버튼을 쓰십시오. 프로그램이 켜져 있어야 하지만, 실행 중이거나 원격 접속 중에도 그 시점까지의 데이터를 빠짐없이 담은 pcm_backup_날짜시각.zip을 받을 수 있어 가장 간편하고 안전합니다. 프로그램이 켜지지 않는 등 이 방법을 쓸 수 없을 때는, 프로그램을 완전히 종료한 뒤 pcm 폴더 전체를 압축해 보관하십시오(data.db 파일 하나만 복사하는 것은 불충분합니다). 중요한 작업(기초데이터 업로드, 라운드 마감 등) 전후로도 백업을 권장합니다.

복원할 때는 기존 pcm 폴더의 이름을 pcm_old로 바꿔 치운 뒤 백업된 pcm 폴더를 그 자리에 넣어야 합니다. 자세한 절차는 6장 「결과 내보내기 및 백업」을 참고하십시오.

Q 데이터를 다른 PC로 이전하려면?

기존 PC에서 프로그램을 완전히 종료한 뒤, 실행 파일 옆의 pcm 폴더 전체를 새 PC로 복사합니다(data.db 파일 하나만 옮기면 안 됩니다). 새 PC에 프로그램을 먼저 설치·실행해 pcm 폴더가 생성되면 프로그램을 종료하고, 그 폴더의 이름을 바꿔 치운 뒤 복사해 온 pcm 폴더를 그 자리에 놓습니다. 기존 폴더 위에 덮어쓰지 마십시오 — 이유와 상세 절차는 6장 「결과 내보내기 및 백업」의 복원 방법과 같습니다. 이후 프로그램을 실행하면 기존 데이터가 그대로 이어집니다.

Q 프로그램을 종료하면 데이터가 사라지나요?

아닙니다. 모든 데이터는 pcm/data.db 파일에 영구 저장됩니다. 트레이 아이콘의 종료로 정상 종료하면 데이터가 그 파일에 완전히 반영된 채로 남으며, 프로그램을 종료하거나 PC를 재시작해도 데이터는 유지됩니다. 단, data.db 파일을 삭제하면 모든 데이터가 영구적으로 소실되므로 주의하십시오.

Q 알 수 없는 오류가 계속 발생합니다. 무엇을 확인해야 하나요?

실행 파일과 같은 폴더의 pcm/logs 폴더에 pcm.날짜.log 형식의 로그 파일이 하루 단위로 쌓입니다. 오류가 발생한 날짜의 로그 파일을 메모장으로 열어 오류가 발생한 시각 부근의 내용을 확인하십시오. 프로그램에는 별도의 콘솔(검은 창)이 뜨지 않으므로, 이 로그 파일이 문제 원인을 확인할 수 있는 사실상 유일한 방법입니다. 직접 해결이 어려우면 해당 부분을 캡처하거나 복사해 시스템 담당자에게 문의하십시오.
