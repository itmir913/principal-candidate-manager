7. 자주 묻는 질문

Q 여러 PC에서 동시에 접속할 수 있나요?

네. 프로그램은 관리자 PC 한 대에서만 실행하고, 담임교사들은 각자의 PC 브라우저에서 관리자 PC의 IP와 포트(예: http://192.168.0.10:8080)로 접속합니다. 동시 접속 인원 제한은 없으나, 반드시 같은 교내 네트워크(LAN) 안에 있어야 합니다.

Q 포트를 변경하려면 어떻게 하나요?

실행 파일과 같은 폴더의 pcm/config.json 파일을 텍스트 편집기로 열어 "port" 값을 원하는 번호로 수정합니다. 수정 후 프로그램을 재시작해야 변경이 반영됩니다. 기본값은 8080입니다.

Q 담임교사가 비밀번호를 분실했다면?

관리자 화면의 학급 관리 탭에서 해당 담임교사 계정을 선택한 후 비밀번호를 초기화할 수 있습니다. 초기화된 비밀번호는 담임교사에게 전달하고, 최초 로그인 후 즉시 변경하도록 안내하십시오.

Q 관리자 비밀번호를 분실했다면?

관리자 비밀번호는 다른 계정으로 초기화할 수 없습니다. 프로그램을 종료한 뒤 DB Browser for SQLite(무료) 같은 도구로 pcm/data.db를 열고, app_configs 테이블에서 admin_password_hash 행을 삭제한 뒤 저장합니다. 이후 프로그램을 재시작하면 관리자 로그인 화면에서 입력하는 비밀번호가 새 관리자 비밀번호로 설정됩니다.

Q 엑셀 파일 업로드 오류가 납니다. 어떻게 해야 하나요?

업로드 양식은 반드시 화면에서 제공하는 샘플 파일을 기준으로 작성해야 합니다. 열 이름(헤더)을 변경하면 오류가 발생합니다. 또한 숫자 열(점수 등)에 문자가 섞이거나 필수 값이 비어 있는 경우, 중복 행이 있는 경우에도 전체 업로드가 거부됩니다. 오류 메시지에 표시된 행 번호와 항목을 확인하여 원인을 수정한 뒤 다시 업로드하십시오. 이 프로그램은 엑셀(Excel)에서 테스트되었으므로, 타사 프로그램의 경우 CSV 파일로 저장하여 가져오기를 시도하십시오.

Q 담임이 지원 정보를 제출한 후 수정할 수 있나요?

라운드가 OPEN 상태인 동안에는 기존 지원을 취소하고 다시 등록하거나, 점수 데이터를 재제출할 수 있습니다. 라운드가 CLOSED 또는 FINALIZED 상태가 되면 담임 교사의 지원 정보 수정·취소가 불가합니다. 수정이 필요한 경우 관리자에게 라운드를 OPEN으로 되돌려 달라고 요청하십시오.

Q 이미 CLOSED 상태인데 점수 기준을 수정해야 한다면?

CLOSED 및 FINALIZED 상태에서는 전형요소 설정(이름·점수 기준표)을 수정할 수 없습니다. CLOSED 라운드라면 라운드 관리 탭에서 다시 열기 버튼으로 OPEN 상태로 되돌린 뒤 수정할 수 있습니다. 다만 이미 마감(FINALIZED)된 다른 라운드가 하나라도 있으면 전형요소 설정 변경이 계속 차단되므로, 이 경우에는 수정할 수 없습니다. 따라서 점수 기준은 첫 라운드를 열기 전에 충분히 검토하여 확정하시기 바랍니다.

Q 동점자가 모집 정원을 초과하면 어떻게 처리하나요?

시스템은 순위 계산만 수행하며, 추천 확정은 관리자가 직접 판단하여 버튼을 눌러야 합니다. 동점자가 발생했을 때는 라운드 관리 탭 → 결과 탭의 학생 목록에서 해당 학생을 클릭하면 전형요소별 세부 점수를 확인할 수 있습니다. 이를 바탕으로 학교 내부 동점자 처리 기준을 적용하여 추천 대상자를 결정한 뒤 추천 확정 버튼을 누르십시오.

Q 데이터 정기 백업은 어떻게 하나요?

프로그램이 실행 중이 아닐 때 pcm/data.db 파일을 복사하여 별도 위치(외장 드라이브, 네트워크 공유 폴더 등)에 보관하십시오. 중요한 작업(기초데이터 업로드, 라운드 마감 등) 전후로 수동 복사하는 것을 권장합니다. 복원이 필요할 때는 프로그램을 종료한 상태에서 백업 파일로 교체한 뒤 재시작하면 됩니다.

Q 데이터를 다른 PC로 이전하려면?

기존 PC의 pcm/data.db 파일을 복사하여 새 PC의 동일한 위치(pcm/ 폴더)에 붙여넣습니다. 새 PC에 프로그램을 먼저 설치한 후, 프로그램을 종료한 상태에서 파일을 교체하십시오. 이후 프로그램을 실행하면 기존 데이터가 그대로 복원됩니다.

Q 프로그램을 종료하면 데이터가 사라지나요?

아닙니다. 모든 데이터는 pcm/data.db 파일에 영구 저장됩니다. 프로그램을 종료하거나 PC를 재시작해도 데이터는 유지됩니다. 단, data.db 파일을 삭제하면 모든 데이터가 영구적으로 소실되므로 주의하십시오.
