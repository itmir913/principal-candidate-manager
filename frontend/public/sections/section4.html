4. 전형요소 예시

전형요소 추가 화면에서 제공하는 6개의 기본 템플릿을 예시로 설명합니다. 실제 학교 상황에 맞게 만점·기준값 등을 수정하여 사용하십시오.

4-1. 교과 내신

대학별 내신 환산등급을 기준으로 점수를 산출합니다. 등록된 점수 기준과 정확히 일치하는 경우에만 점수가 부여됩니다.

점수 산출 방식수치형 입력 구간 탐색 방향정확히 일치 데이터 조회 기준대학별 환산점수 조회 담임교사 입력불가 (관리자 전용) 만점 예시80점

점수 기준 예시

기준값과 정확히 일치하면 해당 점수를 부여합니다. 대학명·모집단위명을 비워두면 모든 대학에 공통 적용됩니다.

기준값 점수 대학명 모집단위명
1 10 한국대 자연계열
2 8 한국대 자연계열
3 6 한국대 자연계열
4 4 한국대 자연계열

4-2. 출결

미인정 출결 횟수에 따라 점수를 산출합니다. 미인정 횟수가 작을수록 배점이 높습니다.

점수 산출 방식수치형 입력 구간 탐색 방향기준값 이하 (작을수록 만점) 데이터 조회 기준기본 조회 담임교사 입력허용 만점 예시10점

점수 기준 예시

입력값이 기준값 이하이면 해당 점수를 부여합니다. 가장 위의 행부터 탐색하므로 기준값을 내림차순으로 작성합니다.

기준값 점수 설명
0 10 미인정 결석일수가 0일이면 10점
1 9 미인정 결석일수가 1일이면 9점
2 8 미인정 결석일수가 2일이면 8점
3 7 미인정 결석일수가 3일이면 7점
4 6 미인정 결석일수가 4일이면 6점
5 5 미인정 결석일수가 5일 이상이면 5점

4-3. 봉사 활동

누적 봉사시간에 따라 점수를 산출합니다. 봉사시간이 많을수록 배점이 높습니다.

점수 산출 방식수치형 입력 구간 탐색 방향기준값 이상 (클수록 만점) 데이터 조회 기준기본 조회 담임교사 입력허용 만점 예시5점

점수 기준 예시

입력값이 기준값 이상이면 해당 점수를 부여합니다. 가장 위의 행부터 탐색하므로 기준값을 내림차순으로 작성합니다.

기준값 점수 설명
40 5 봉사시간이 40시간 이상이면 5점
30 4 봉사시간이 30시간 이상 40시간 미만이면 4점
20 3 봉사시간이 20시간 이상 30시간 미만이면 3점
0 0 봉사시간이 20시간 미만이면 0점

4-4. 수상 실적

수상 실적을 등록하고 해당하는 항목 중 가장 높은 점수 1건만 반영합니다.

점수 산출 방식선택형 입력 복수 활동 처리최대 1개만 인정 (최고점 반영) 데이터 조회 기준기본 조회 담임교사 입력허용 만점 예시3점

점수 기준 예시

기초 데이터의 범주값이 점수 기준의 범주명과 정확히 일치해야 합니다. 여러 범주에 해당하더라도 가장 높은 점수 1건만 반영됩니다.

범주 점수 설명
금상 3 '금상' 해당 시 3점
은상 2 '은상' 해당 시 2점
동상 1 '동상' 해당 시 1점
해당없음 0 어떤 범주에도 해당하지 않으면 0점

4-5. 교내 활동

교내 활동 실적을 등록하고 해당하는 모든 항목의 점수를 합산하여 반영합니다. 합산 결과는 전형요소 만점을 초과할 수 없습니다.

점수 산출 방식선택형 입력 복수 활동 처리중복 선택 가능 (점수 합산) 데이터 조회 기준기본 조회 담임교사 입력허용 만점 예시2점

점수 기준 예시

해당하는 모든 범주의 점수를 합산합니다. 합산 결과가 만점(2점)을 초과하면 만점으로 처리됩니다.

범주 점수 설명
학생자치회 임원 2 '학생자치회 임원' 해당 시 2점 합산
동아리 임원 1 '동아리 임원' 해당 시 1점 합산
해당없음 0 어떤 범주에도 해당하지 않으면 0점

4-6. 생활태도

징계·학교폭력·선도처분 미이수 등 감점 사유에 해당하는 모든 항목의 점수(음수)를 합산합니다. 만점은 0점이며, 사유가 없으면 감점 없이 0점입니다.

점수 산출 방식선택형 입력 복수 활동 처리중복 선택 가능 (점수 합산) 데이터 조회 기준기본 조회 담임교사 입력허용 만점0점 (감점 전용)

점수 기준 예시

감점 항목은 점수를 음수로 입력합니다. 해당하는 모든 항목의 점수가 합산되어 최종 점수는 0점 이하가 됩니다.

범주 점수 설명
학교폭력 가해 -10 '학교폭력 가해' 해당 시 10점 감점
징계 -5 '징계' 해당 시 5점 감점
선도처분 미이수 -3 '선도처분 미이수' 해당 시 3점 감점
해당없음 0 어떤 범주에도 해당하지 않으면 0점
