3. 관리자 사전 설정

라운드를 열기 전 학교장추천 담당자가 반드시 완료해야 하는 설정입니다. 아래 항목을 순서대로 진행하십시오.

시작하기 전에 다음을 준비하십시오.

  • 학교장추천전형 선발 기준 문서 — 전형요소 항목과 만점, 기준표가 확정된 것
  • 학급·담임 명단 — 학년·반·담임명 (3-1에서 사용)
  • 학생 명렬표 — 재학생: 학년·반·번호·이름 / 졸업생: 학생코드·이름 (3-2에서 사용)
  • 각 전형요소의 기초 데이터 — 봉사 시간, 미인정 출결 횟수 등 학생별 자료 (3-3에서 사용)

선발 기준이 확정되지 않은 상태에서 라운드를 열면 전형요소를 수정할 수 없습니다.

단계 간 선행 조건이 있습니다. 전형요소(3-3)를 먼저 설정한 후 대학·모집단위(3-4) 설정으로 넘어갑니다. 대학별 환산점수 방식의 전형요소가 있다면 기초 데이터(내신 석차연명부 등)를 먼저 업로드해야 대학명·모집단위명이 자동 생성됩니다. 해당 방식의 전형요소가 하나도 없다면 대학 설정 탭에서 대학·모집단위를 직접 추가합니다. 대학·모집단위가 준비된 이후에 정원과 배점을 설정할 수 있습니다.

3-1. 학급·담임 계정 설정

관리자로 로그인한 후 학급 관리 탭에서 학년·반별 담임교사 계정을 일괄 생성합니다. 관리자 화면의 양식 다운로드 버튼으로 양식 파일을 받아 학급을 작성한 뒤 가져오기 버튼으로 업로드하면 담임교사 계정이 자동 생성됩니다.

엑셀 파일에 입력한 비밀번호가 그대로 계정 비밀번호가 됩니다. 해당 비밀번호를 담임교사에게 안내하십시오. 담임교사가 비밀번호를 분실할 경우 관리자는 학급 관리 탭에서 새로운 비밀번호를 설정할 수 있습니다.

학년 반 담임명 비밀번호
1 1 담임A teacher1!
1 2 담임B teacher2@
2 1 담임C teacher3#
3 1 담임D teacher4$

3-2. 학생 명단 등록

관리자 화면의 학생 관리 탭에서 재학생과 졸업생을 각각 등록합니다. Excel 파일(.xlsx)로 일괄 가져오거나 + 추가 버튼으로 한 명씩 직접 입력할 수 있습니다.

가져오기는 추가·업데이트 방식으로 동작합니다. 파일에 없는 기존 학생은 삭제되지 않으며, 같은 식별자(재학생: 학년·반·번호, 졸업생: 학생코드)가 이미 있으면 이름 등 정보를 업데이트하고, 없으면 새로 추가합니다.

단, 라운드가 종료(CLOSED)된 동안에는 이미 그 라운드에 결과가 있는 학생의 재학/졸업 구분을 바꿀 수 없습니다(가져오기 전체가 거부됩니다). 저장된 순위가 종료 시점의 재학/졸업 구분을 기준으로 계산된 값이기 때문입니다. 바꾸려면 라운드를 다시 열고 명단을 반영한 뒤 다시 종료하십시오. 이름 수정과 신규 학생 추가는 종료 중에도 가능합니다.

재학생 가져오기 양식

재학생은 학년·반·번호만 입력하면 됩니다. 학생코드는 시스템이 자동 생성하므로 파일에 포함하지 않습니다. 같은 학년·반·번호가 이미 등록된 경우 이름이 업데이트됩니다.

학년 반 번호 이름
1 1 1 학생A
1 2 15 학생B
3 1 22 학생C

졸업생 가져오기 양식

학생코드를 직접 입력합니다. 학생코드는 정해진 양식이 없으니 관리자가 알아보기 쉽도록 원하는 값으로 지정하십시오. 같은 학생코드가 이미 등록된 경우 이름과 졸업연도가 업데이트됩니다.

학생코드 이름 졸업연도
20240001 졸업생A 2024
20230015 졸업생B 2023

가져오기 공통 주의사항

아래 두 가지는 3-1·3-2·3-3의 모든 엑셀 가져오기에 공통으로 적용됩니다.

업로드 파일 크기 제한

한 번에 올릴 수 있는 파일 크기는 최대 20MB입니다. 초과하면 "업로드 파일 크기가 너무 큽니다 (최대 20MB)" 메시지가 표시됩니다. 석차연명부처럼 대용량 파일은 학교(학년)별로 나눠 업로드하십시오.

가져오기 실패 시 대처

가져오기는 한 건이라도 오류가 있으면 전체를 저장하지 않고 원래 상태로 되돌립니다. 화면에 오류 목록(행 번호·오류 내용)이 표시됩니다. 오류 목록에서 해당 행을 찾아 수정한 뒤 파일 전체를 다시 업로드하십시오. 오류가 난 행만 별도로 업로드할 수 없습니다. 흔한 오류 예시: 헤더 열 이름이 다름, 동일 행 중복, 숫자 칸에 문자 입력, 날짜 서식 셀.

3-3. 전형요소 설정

관리자 화면의 전형요소 설정 탭에서 점수 산출에 사용할 전형요소를 정의합니다. 유형과 적용 범위의 조합에 따라 아래와 같이 구분됩니다.

3-3 설정 순서 요약

  1. 전형요소 추가 — 유형·적용 범위 선택, 만점 입력
  2. 점수 기준표 입력 — 기준값(또는 범주)별 점수 등록
  3. 기초 데이터 업로드 — 담임교사 직접 입력 전형요소는 생략 가능
  4. 점수 계산 테스트로 검증

아래에서 각 단계를 순서대로 설명합니다.

수치형 입력

담임교사가 숫자를 입력하면 시스템이 구간 기준에 따라 점수를 자동 계산합니다.

선택형 입력

미리 정의된 선택지 중 하나 또는 여러 개를 고르면 해당 배점을 합산합니다.

점수 직접 입력

담임교사가 전형요소 점수를 직접 숫자로 입력합니다.

기본 조회

모든 지원자에게 동일한 기준을 적용합니다. 대부분의 전형요소에 사용합니다.

대학별 환산점수 조회

지원한 대학·모집단위 조합별로 서로 다른 기준을 적용합니다. 대학의 모집단위마다 내신 등급이나 점수가 다를 때 활용합니다.

전형요소 추가 절차

  1. 관리자 화면 왼쪽 사이드바에서 전형요소 설정 탭을 클릭합니다.
  2. + 전형요소 추가 버튼을 클릭하면 오른쪽에 추가 폼이 표시됩니다.
  3. 이름을 입력하고, 입력 유형(수치형 입력/선택형 입력/점수 직접 입력)과 데이터 조회 기준(기본 조회/대학별 환산점수 조회)을 선택한 뒤 만점을 입력하고 저장합니다.
  4. 추가된 전형요소를 클릭하면 상세 화면(점수 기준 탭 / 기초 데이터 탭)이 열립니다. 여기서 점수 기준표와 기초 데이터를 입력합니다.

입력 유형별 세부 설정

각 입력 유형에 따라 점수 산출 방식을 세부적으로 설정합니다.

수치형 입력

담임교사가 숫자를 직접 입력합니다. 이 숫자는 내신 등급, 미인정 결석일수, 봉사 시간 등 실제 점수 계산에 활용되는 수치입니다.

기준값 단위(선택) — 수치형 입력에만 나타나는 항목입니다. 담임교사가 기초 데이터를 입력할 때 화면에 표시할 단위를 지정합니다(예: "시간"으로 설정하면 입력란에 "데이터 입력 (시간)"이 표시됩니다). 비워 두면 단위가 표시되지 않습니다. 점수 직접 입력의 단위는 프로그램이 '점'으로 자동 고정하므로 입력할 수 없고, 선택형 입력에는 이 항목 자체가 없습니다.

⚙️ 구간 탐색 방향 설정

기준값 이상 (클수록 만점)

입력된 값이 설정한 기준값보다 크거나 같을 때 만점 또는 가산점을 부여합니다. (예: 봉사시간, 수상 실적 등)

기준값 이하 (작을수록 만점)

입력된 값이 설정한 기준값보다 작거나 같을 때 만점 또는 가산점을 부여합니다. (예: 미인정 결석일수, 감점 항목 등)

정확히 일치

입력된 수치가 지정된 특정 기준값과 정확하게 일치할 때만 해당 점수를 부여합니다. (예: 대학별 내신 환산등급 등)

선택형 입력

담임교사가 미리 정의된 선택지 중 하나를 고릅니다. 이 선택지는 학생회 임원, 동아리 회장 등 범주형 활동입니다.

⚙️ 복수 활동 처리 방식

중복 선택 가능 (점수 합산)

여러 개의 활동을 동시에 선택할 수 있으며, 선택된 모든 항목의 배점을 합산하여 최종 점수에 반영합니다.

최대 1개만 인정 (최고점 반영)

여러 개의 활동을 고르더라도, 그중 배점이 가장 높은 단 하나의 활동 점수만 최종 점수로 인정합니다.

점수 직접 입력

담임교사가 전형요소 점수를 직접 숫자로 입력합니다. 구간 기준이나 선택지 없이 점수 자체를 입력하므로, 면접 점수, 포트폴리오 평가 등 담임교사가 자체적으로 판단해 부여하는 항목에 사용합니다.

점수 기준표 업로드 방법

전형요소 상세 화면의 점수 기준 탭에서 가져오기 버튼으로 엑셀 파일을 올리거나, 행을 직접 추가할 수 있습니다. 엑셀 파일의 필수 열 이름은 아래와 같습니다.

  • 수치형 입력: 기준값, 점수
  • 선택형 입력: 범주, 점수
  • 대학별 환산점수 조회 방식이면 대학명, 모집단위명 열을 더 넣을 수 있습니다(선택). 넣으면 대학·모집단위마다 다른 기준이 적용되고, 넣지 않으면 모든 대학에 같은 기준이 적용됩니다. 두 열 중 하나만 채우면 오류가 납니다.

4. 전형요소 예시 절의 점수 기준 예시 표는 이 양식을 그대로 엑셀로 옮겨 사용할 수 있습니다. 단, 종료(CLOSED) 또는 마감(FINALIZED) 상태의 라운드가 이미 존재하면 점수 기준 수정이 차단됩니다.

점수 계산 테스트

점수 기준을 입력한 뒤, 전형요소 상세 화면 우측의 "점수 계산 테스트" 카드에 값을 넣으면 실제 계산될 점수를 즉시 확인할 수 있습니다. 저장되지 않으므로 여러 값을 시험해 볼 수 있습니다. 대학별 환산점수 조회 방식이라면 대학·모집단위를 먼저 선택한 뒤 값을 입력합니다.

전형요소 점수 산출 구조

전형요소 점수를 계산하려면 두 가지가 필요합니다. 실제 학생의 활동·성적 수치인 기초 데이터와, 이를 점수로 환산하는 점수 기준입니다. 프로그램은 각 전형요소마다 이 두 요소를 결합하여 점수를 자동 산출합니다.

  1. ① 기초 데이터 수집

    봉사시간·미인정 결석·내신 등급 등 실제 학생의 수치 데이터입니다. 전형요소 유형에 따라 담임교사가 직접 입력하거나, 관리자가 일괄 업로드합니다.

  2. ② 점수 기준 적용

    기초 데이터를 점수로 환산하는 구간표 또는 선택지 배점입니다. 관리자가 전형요소별로 설정하며, 라운드를 열기 전 모든 전형요소에 대해 빠짐없이 입력해야 합니다.

  3. → 전형요소 점수 산출

    시스템이 두 요소를 결합하여 점수를 자동으로 계산합니다. 담임교사가 지원서를 제출하는 시점에 계산되어 저장됩니다.

기초 데이터 첫 업로드 양식

처음 업로드할 때는 아래 열 이름으로 엑셀 파일을 만들어 전형요소 상세 화면의 기초 데이터 탭에서 가져오기 버튼으로 올립니다.

구분 필수 열 대학별 환산점수 조회 추가 열
재학생 학년, 반, 번호, 이름, 값 대학명, 모집단위명
졸업생 학생코드, 이름, 값 대학명, 모집단위명

이미 등록된 데이터가 있다면 아래 기초 데이터 내보내기로 내려받은 파일의 헤더를 참고해도 됩니다. 단, 데이터가 한 건도 없으면 내보낼 파일이 없으므로 위 표를 직접 참고하십시오.

📤기초 데이터 내보내기

전형요소 설정 탭에서 전형요소를 선택한 뒤 기초 데이터 탭을 열면 현재 저장된 데이터를 내보낼 수 있습니다. 재학생·졸업생 구분을 선택하면 해당 구분의 import 양식과 동일한 헤더로 파일이 내려받아집니다. 내려받은 파일을 수정한 뒤 그대로 재업로드할 수 있습니다.

학교장추천전형 선발 기준은 학교마다 다릅니다. 관리자는 자교의 학교장추천전형 대상자 선발 기준을 먼저 확인한 후, 그에 맞춰 전형요소를 설정하십시오. 어떻게 구성해야 할지 참고가 필요하다면 4. 전형요소 예시 섹션에서 6가지 예시를 확인할 수 있습니다.

3-4. 대학·모집단위 설정

관리자 화면의 대학 설정 탭에서 추천 대상 대학·모집단위를 관리합니다. 대학명과 모집단위명은 대학별 환산점수 조회 방식으로 설정된 전형요소의 기초 데이터(석차연명부 등)를 업로드하면 자동으로 생성됩니다. 해당 방식의 전형요소가 없다면 이 탭에서 대학·모집단위를 직접 추가할 수 있습니다. 자세한 내용은 4-1. 교과 내신 전형요소 예시를 참고하십시오.

관리자는 대학·모집단위 설정에서 다음 항목을 직접 설정해야 합니다.

  • 대학별 전체 정원 — 해당 대학에 우리 학교가 추천할 수 있는 총 인원
  • 모집단위별 정원 — 특정 모집단위에 별도 인원 제한이 있는 경우 설정
  • 재학생 우선 여부 — 재학생을 졸업생보다 점수와 무관하게 우선 추천합니다. 순위 산출에 직접 영향을 미치므로 정확히 설정하십시오.
    • 대학에 설정하면 그 대학 전체 순위에 적용되며, 그 대학의 모든 모집단위도 함께 켜집니다. 대학 설정을 다시 끄면 모집단위 설정도 함께 꺼집니다.
    • 모집단위에만 설정하면(대학은 끔) 그 모집단위 안에서만 재학생이 먼저 추천됩니다. 대학 전체 정원으로 인원을 줄일 때도 그 모집단위 내부 순서는 유지되며, 다른 모집단위 지원자와의 비교는 대학 설정을 따릅니다.
    • 라운드가 종료(CLOSED)된 동안에는 변경할 수 없습니다. 저장된 순위가 종료 시점의 설정을 기준으로 계산된 값이기 때문입니다. 바꾸려면 라운드를 다시 열고 설정을 고친 뒤 다시 종료하십시오(종료 시 순위가 재계산됩니다). 정원 변경은 종료 중에도 가능합니다.
