3. 관리자 사전 설정

라운드를 열기 전 학교장추천 담당자가 반드시 완료해야 하는 설정입니다. 아래 항목을 순서대로 진행하십시오.

단계 간 선행 조건이 있습니다. 전형요소(3-3)를 먼저 설정한 후, COMPOSITE 전형요소가 있다면 기초 데이터를 업로드해야 대학·모집단위(3-4)가 자동 생성됩니다. 대학·모집단위가 생성된 이후에 정원과 배점을 설정할 수 있습니다.

3-1. 학급·담임 계정 설정

관리자로 로그인한 후 학급 관리 탭에서 학년·반별 담임교사 계정을 일괄 생성합니다. 관리자 화면의 양식 다운로드 버튼으로 양식 파일을 받아 학급을 작성한 뒤 가져오기 버튼으로 업로드하면 담임교사 계정이 자동 생성됩니다.

엑셀 파일에 입력한 비밀번호가 그대로 계정 비밀번호가 됩니다. 해당 비밀번호를 담임교사에게 안내하십시오. 담임교사가 비밀번호를 분실할 경우 관리자는 학급 관리 탭에서 새로운 비밀번호를 설정할 수 있습니다.

학년 반 담임명 비밀번호
1 1 담임A teacher1!
1 2 담임B teacher2@
2 1 담임C teacher3#
3 1 담임D teacher4$

3-2. 학생 명단 등록

관리자 화면의 학생 관리 탭에서 재학생과 졸업생을 각각 등록합니다. Excel 파일(.xlsx)로 일괄 가져오거나 + 추가 버튼으로 한 명씩 직접 입력할 수 있습니다.

가져오기는 추가·업데이트 방식으로 동작합니다. 파일에 없는 기존 학생은 삭제되지 않으며, 같은 식별자(재학생: 학년·반·번호, 졸업생: 학생코드)가 이미 있으면 이름 등 정보를 업데이트하고, 없으면 새로 추가합니다.

재학생 가져오기 양식

재학생은 학년·반·번호만 입력하면 됩니다. 학생코드는 시스템이 자동 생성하므로 파일에 포함하지 않습니다. 같은 학년·반·번호가 이미 등록된 경우 이름이 업데이트됩니다.

학년 반 번호 이름
1 1 1 학생A
1 2 15 학생B
3 1 22 학생C

졸업생 가져오기 양식

학생코드를 직접 입력합니다. 학생코드는 정해진 양식이 없으니 관리자가 알아보기 쉽도록 원하는 값으로 지정하십시오. 같은 학생코드가 이미 등록된 경우 이름과 졸업연도가 업데이트됩니다.

학생코드 이름 졸업연도
20240001 졸업생A 2024
20230015 졸업생B 2023

3-3. 전형요소 설정

관리자 화면의 전형요소 설정 탭에서 점수 산출에 사용할 전형요소를 정의합니다. 유형과 적용 범위의 조합에 따라 아래와 같이 구분됩니다.

NUMERIC

담임교사가 숫자를 입력하면 시스템이 구간 기준에 따라 점수를 자동 계산합니다.

CATEGORY

미리 정의된 선택지 중 하나 또는 여러 개를 고르면 해당 배점을 합산합니다.

MANUAL

담임교사가 전형요소 점수를 직접 숫자로 입력합니다.

SIMPLE — 공통 기준

모든 지원자에게 동일한 기준을 적용합니다. 대부분의 전형요소에 사용합니다.

COMPOSITE — 조합별 기준

지원한 대학·모집단위 조합별로 서로 다른 기준을 적용합니다. 대학의 모집단위마다 내신 등급이나 점수가 다를 때 활용합니다.

입력 유형별 세부 설정

각 입력 유형에 따라 점수 산출 방식을 세부적으로 설정합니다.

NUMERIC — 수치형 입력

담임교사가 숫자를 직접 입력합니다. 이 숫자는 내신 등급, 미인정 결석일수, 봉사 시간 등 실제 점수 계산에 활용되는 수치입니다.

⚙️ 구간 탐색 방향 설정

기준값 이상 (클수록 만점)

입력된 값이 설정한 기준값보다 크거나 같을 때 만점 또는 가산점을 부여합니다. (예: 봉사시간, 수상 실적 등)

기준값 이하 (작을수록 만점)

입력된 값이 설정한 기준값보다 작거나 같을 때 만점 또는 가산점을 부여합니다. (예: 미인정 결석일수, 감점 항목 등)

정확히 일치

입력된 수치가 지정된 특정 기준값과 정확하게 일치할 때만 해당 점수를 부여합니다. (예: 특정 취득 학점 등)

CATEGORY — 선택형 입력

담임교사가 미리 정의된 선택지 중 하나를 고릅니다. 이 선택지는 학생회 임원, 동아리 회장 등 범주형 활동입니다.

⚙️ 복수 활동 처리 방식

중복 선택 가능 (점수 합산)

여러 개의 활동을 동시에 선택할 수 있으며, 선택된 모든 항목의 배점을 합산하여 최종 점수에 반영합니다.

최대 1개만 인정 (최고점 반영)

여러 개의 활동을 고르더라도, 그중 배점이 가장 높은 단 하나의 활동 점수만 최종 점수로 인정합니다.

MANUAL — 교사 직접 입력

담임교사가 전형요소 점수를 직접 숫자로 입력합니다. 구간 기준이나 선택지 없이 점수 자체를 입력하므로, 면접 점수, 포트폴리오 평가 등 담임교사가 자체적으로 판단해 부여하는 항목에 사용합니다.

전형요소 점수 산출 구조

전형요소 점수를 계산하려면 두 가지가 필요합니다. 실제 학생의 활동·성적 수치인 기초 데이터와, 이를 점수로 환산하는 점수 기준입니다. 프로그램은 각 전형요소마다 이 두 요소를 결합하여 점수를 자동 산출합니다.

  1. ① 기초 데이터 수집

    봉사시간·미인정 결석·내신 등급 등 실제 학생의 수치 데이터입니다. 전형요소 유형에 따라 담임교사가 직접 입력하거나, 관리자가 일괄 업로드합니다.

  2. ② 점수 기준 적용

    기초 데이터를 점수로 환산하는 구간표 또는 선택지 배점입니다. 관리자가 전형요소별로 설정하며, 라운드를 열기 전 모든 전형요소에 대해 빠짐없이 입력해야 합니다.

  3. → 전형요소 점수 산출

    시스템이 두 요소를 결합하여 점수를 자동으로 계산합니다. 담임교사가 지원서를 제출하는 시점에 계산되어 저장됩니다.

📤기초 데이터 내보내기

전형요소 설정 탭에서 전형요소를 선택한 뒤 기초 데이터 탭을 열면 현재 저장된 데이터를 내보낼 수 있습니다. 재학생·졸업생 구분을 선택하면 해당 구분의 import 양식과 동일한 헤더(재학생: 학년·반·번호·이름·값 / 졸업생: 학생코드·이름·값)로 파일이 내려받아집니다. 내려받은 파일을 수정한 뒤 같은 구분으로 그대로 재업로드할 수 있습니다.

학교장추천전형 선발 기준은 학교마다 다릅니다. 관리자는 자교의 학교장추천전형 대상자 선발 기준을 먼저 확인한 후, 그에 맞춰 전형요소를 설정하십시오. 어떻게 구성해야 할지 참고가 필요하다면 4. 전형요소 예시 섹션에서 6가지 예시를 확인할 수 있습니다.

3-4. 대학·모집단위 설정

관리자 화면의 대학 설정 탭에서 추천 대상 대학·모집단위를 관리합니다. 대학명과 모집단위명은 COMPOSITE 전형요소의 기초 데이터(석차연명부 등)를 업로드하면 자동으로 생성됩니다. 자세한 내용은 4-1. 교과 내신 전형요소 예시를 참고하십시오.

관리자는 대학·모집단위 설정에서 다음 항목을 직접 설정해야 합니다.

  • 대학별 전체 정원 — 해당 대학에 우리 학교가 추천할 수 있는 총 인원
  • 모집단위별 정원 — 특정 모집단위에 별도 인원 제한이 있는 경우 설정
  • 재학생 우선 여부 — 동점자 발생 시 재학생을 졸업생보다 우선 추천합니다. 순위 산출에 직접 영향을 미치므로 정확히 설정하십시오.
  • 모집단위별 전형요소 배점 — 각 모집단위에서 전형요소별 최대 배점을 입력합니다. 배점이 입력되지 않은 모집단위는 지원자의 점수가 계산되지 않습니다.
