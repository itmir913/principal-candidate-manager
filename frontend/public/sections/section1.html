1. 시작하기 전에

시작하기 전에 준비할 것

  • 선발 기간 내내 켜 둘 수 있는 Windows 컴퓨터 한 대 (학내 네트워크에 연결되어 있어야 합니다)
  • 학교의 학교장추천 선발 기준 — 어떤 항목을 몇 점으로 반영하는지 확정된 문서
  • 학급·담임 명단 (학년·반·담임명)
  • 학생 명렬표 (재학생: 학년·반·번호·이름 / 졸업생: 학생코드·이름)
  • 각 평가 항목의 학생별 자료 (내신 등급, 봉사 시간 등)

필요한 컴퓨터 지식은 파일 압축 풀기와 브라우저 사용뿐입니다. 서버·IP 같은 용어를 몰라도 이 매뉴얼의 순서대로 따라 하면 됩니다.

시스템 요구 환경

  • 🖥️운영체제: Windows 10 / 11 (x64)
  • 🌐브라우저: Chrome, Edge, Firefox 최신 버전 권장
  • 🔌네트워크: 학내 LAN (선발 업무에는 인터넷 연결이 필요하지 않습니다. 새 버전 확인·내려받기에만 인터넷이 필요합니다.)

설치하고 처음 켜기

  1. 1 공식 홈페이지(https://luminousky.com/teacher-utility-kit/principal-candidate-manager/)에서 최신 버전의 .zip 파일을 다운로드합니다.
  2. 2 다운로드한 압축 파일을 원하는 폴더에 압축 해제합니다. 압축을 풀면 exe 파일 하나가 나옵니다. 이 파일이 있는 자리에 pcm 폴더가 생성되고 모든 데이터가 그 안에 저장되므로, 바탕화면보다는 별도 폴더를 만들어 두는 것을 권장합니다.
  3. 3

    principal-candidate-manager.exe를 실행합니다.

    ⚠️처음 실행할 때 나타나는 창 두 가지

    • "Windows의 PC 보호" 파란 창이 뜨면 → 추가 정보를 누른 뒤 실행 버튼을 누릅니다. 인터넷에서 내려받은 프로그램에 Windows가 표시하는 일반적인 안내입니다.
    • "Windows Defender 방화벽에서 이 앱의 일부 기능을 차단했습니다" 창이 뜨면 → 개인 네트워크 항목에 체크하고 액세스 허용을 누릅니다. 이 창에서 취소를 누르면 다른 교사가 접속할 수 없습니다. 실수로 취소했다면 프로그램을 종료한 뒤 다시 실행하십시오.
  4. 4

    실행하면 윈도우 시스템 트레이(화면 우측 하단)에 아이콘이 나타납니다.

    트레이 아이콘을 오른쪽 클릭하면 메뉴가 나타납니다. 항목은 세 개입니다.

    • 시작 시 자동 실행 — 체크되어 있으면 컴퓨터를 켤 때 프로그램이 자동으로 시작됩니다. 처음 설치하면 체크된 상태이며, 클릭할 때마다 켜고 끌 수 있습니다.
    • 열기 — 이 컴퓨터의 브라우저에서 시스템 화면을 엽니다.
    • 종료 — 프로그램을 완전히 종료합니다. 종료하면 다른 교사도 접속할 수 없습니다.

    트레이 아이콘이 보이지 않으면 시계 왼쪽의 ∧(숨겨진 아이콘 표시)를 눌러 확인하십시오.

    트레이 아이콘을 오른쪽 클릭한 후 열기를 선택하면 브라우저가 자동으로 열립니다.

  5. 5

    브라우저가 열리면 다음 순서로 초기 설정이 진행됩니다.

    ①

    이용 안내 동의

    프로그램 이용 안내와 라이선스 안내가 표시됩니다. 이 프로그램은 선발 업무를 돕는 보조 도구이며, 최종 선발 결과의 확인과 결정 책임은 학교에 있습니다. 라이선스는 PolyForm Noncommercial 1.0.0으로, 학교·교육청 등 비영리 목적에 한해 무료로 사용할 수 있습니다. 화면 아래 "위 내용을 확인하였으며, 이에 동의합니다." 체크박스를 선택한 뒤 동의하고 계속하기 버튼을 누릅니다.

    ②

    관리자 비밀번호 설정

    새 비밀번호와 비밀번호 확인에 같은 값을 입력하고 시작하기를 누릅니다. 비밀번호는 8자 이상이어야 하며, 두 칸이 다르면 버튼이 눌리지 않습니다. 이 비밀번호는 성적 확인·라운드 관리 등 관리자 기능 전체에 사용됩니다.

    ⚠️

    관리자 비밀번호는 안전한 곳에 기록해 두십시오. 다른 계정으로 초기화할 수 없습니다. 분실했을 때 데이터를 지우지 않고 되살리는 방법이 7장 자주 묻는 질문에 있습니다. data.db 파일은 절대 먼저 삭제하지 마십시오 — 입력한 모든 데이터가 함께 사라집니다.

    ✅ 성공 확인

    관리자 화면 왼쪽에 개요·학급 관리·학생 관리 등 메뉴가 보이면 설치가 완료된 것입니다.

다른 교사에게 알려줄 주소 확인하기

  1. 1 담당자 컴퓨터에서 트레이 아이콘 → 열기로 화면을 엽니다.
  2. 2 관리자로 로그인합니다.
  3. 3 왼쪽 사이드바에서 개요를 클릭하면 서버 접속 정보 칸에 http://192.168.0.10:8080 형태의 주소가 표시됩니다. 숫자는 학교마다 다릅니다.
  4. 4 오른쪽 복사 버튼을 누르면 주소가 복사됩니다. 이 주소를 그대로 담임교사에게 전달하십시오.

주소 뒤의 :8080까지 포함해야 접속됩니다. 앞부분 숫자만 전달하면 담임교사 화면에 아무것도 열리지 않습니다.

표시된 주소가 http://127.0.0.1:8080이면 네트워크에서 이 컴퓨터의 주소를 찾지 못한 것입니다. 이 주소는 담당자 컴퓨터에서만 열립니다. 유선 랜선 연결 여부를 확인한 뒤 프로그램을 재시작하십시오.

켜 두어야 하는 이유

이 프로그램은 담당자 컴퓨터를 서버로 사용합니다. 프로그램을 종료하거나 컴퓨터를 끄면 그 순간부터 담임교사는 접속할 수 없습니다(입력한 데이터는 사라지지 않습니다). 담임교사 입력 기간에는 컴퓨터를 켜 두십시오.

컴퓨터를 껐다 켜도 트레이의 시작 시 자동 실행이 켜져 있으면 프로그램이 자동으로 다시 시작됩니다.

프로그램을 완전히 끄려면 트레이 아이콘 → 종료를 사용하십시오. 창을 닫는 것만으로는 종료되지 않습니다.

🖥️별도 데스크톱 컴퓨터에서 실행하는 경우

대교협 진학 컴퓨터 등 교사망에 연결된 전용 컴퓨터에 설치하면 담당자 PC 종료 여부에 관계없이 안정적으로 운영할 수 있습니다.

데이터가 저장되는 곳

모든 데이터는 실행 파일과 같은 폴더의 pcm/data.db 파일에 저장됩니다. 프로그램을 종료하거나 PC를 재시작해도 데이터는 유지됩니다.

정기적으로 백업해 두십시오. 가장 간단한 방법은 관리자 화면 왼쪽 사이드바의 업데이트 & 백업 탭에서 DB 백업 다운로드 버튼을 누르는 것입니다. 내려받은 파일을 외장 드라이브 등 다른 곳에 보관하십시오. 자세한 내용은 6장을 참고하십시오.

기록(로그) 파일

프로그램의 동작 기록은 pcm/logs/ 폴더에 날짜별로 저장됩니다 (예: pcm.2026-07-21.log). 화면에 원인을 알 수 없는 오류가 계속 나타나면 그날 날짜의 파일을 열어 마지막 부분을 확인하거나, 문의 시 이 파일을 함께 보내십시오. 이 파일은 지워도 프로그램 동작에는 영향이 없습니다.

문제가 생겼을 때

"포트 8080에 서버를 시작할 수 없습니다" 창이 뜬다면

다른 프로그램이 같은 번호를 쓰고 있는 것입니다. 아래 포트 변경 방법대로 pcm/config.json의 숫자를 8081처럼 바꾸고 다시 실행하십시오. 포트 번호를 바꾸면 담임교사에게 알려줄 주소의 뒷자리도 함께 바뀝니다.

트레이 아이콘 위에 "(서버 오류)"가 표시된다면

데이터 파일을 열지 못한 상태입니다. 화면을 열면 오류 내용이 표시됩니다. pcm/logs/의 그날 기록 파일과 함께 문의하십시오.

포트 변경

기본 포트는 8080입니다. 다른 포트로 변경하려면 실행 파일과 같은 폴더의 pcm/config.json을 텍스트 편집기로 열어 수정합니다.

{
  "port": 8080
}

수정 후 프로그램을 재시작해야 반영됩니다.

여기까지 됐다면

담당 교사는 이어서 3장 「관리자 사전 설정」으로 넘어가십시오. 학급·담임 계정을 만들어야 담임교사가 로그인할 수 있습니다.

막혔을 때

  2. 2. 7장 자주 묻는 질문에 비밀번호 분실·업로드 오류·백업 등 자주 겪는 문제의 해결 방법이 있습니다.
